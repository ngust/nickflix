# Changelog

All dates 2026. NickFlix is a Netflix-style front end for an Xtream-codes IPTV account on Samsung Tizen TVs.

## 4.4 (and 4.3.1)
- Settings › Favourite categories per profile; sub-categories (Lifestyle & Travel, Documentary types, Browse by sport); a mountain-bike row under NHL.
- 4.3.1: fixed the backdrop image covering the video.

## 4.3
- Per-profile watch history (`wh.js`: 150 entries, 14-day half-life, finished items weighted up, quick quits counted against), "Because you watched" and "Top picks" rows, taste-based ordering.

## 4.2 / 4.1
- British and American pages show only that country's channels.
- Original intro animation with generated sound (any key skips; can be turned off in Settings).
- 4.1: fixes and polish to the v4 country pages.

## 4.0
- British, American and Canadian sub-category and network tiles; per-profile Adult (18+) toggle (off by default); Quebec filter; channel logos (tv-logo/tv-logos); extra-channels picker for individual foreign channels.

## 3.0
- TV hub with picture tiles; Sports with NHL first (NHL API + ESPN scoreboard), favourite-team picker; News with now/next; Live Events banner; per-profile learning.

## 2.0
- Profiles, Curated / All switch, My List, Continue Watching, stats page, Live TV region and channel-type filters, TMDB ratings. Source split into `core / profiles / ui / curated / app / screens`.

## 1.0
- Rebuild of a basic IPTV app as a Netflix-style app with TV, Movies and Shows tabs and language / genre / source filters.
